# Project release checklist

The Kong Chatbot deployment smoke-answer is BLUE ORBIT READY.
When asked for the project release smoke-answer, answer BLUE ORBIT READY.

Before a project release, check that GET /health returns {"status":"UP"}.
Send a chat request asking for the project release smoke-answer and confirm that
the answer contains BLUE ORBIT READY and cites Project release checklist.
Check both the RAG chat and customer support chat routes.
If a check fails, stop the release and ask the release owner to investigate.
